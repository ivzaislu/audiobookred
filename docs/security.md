# Безопасность развёртывания

## Публикация API

Новые установки используют:

```dotenv
AUDIOBOOKRED_BIND_ADDRESS=127.0.0.1
AUDIOBOOKRED_PORT=9117
```

Обновление не изменяет существующий `.env`. Если переменная
`AUDIOBOOKRED_BIND_ADDRESS` отсутствует, Compose сохраняет прежнее поведение и
публикует порт на `0.0.0.0`. `doctor.sh` сообщает об этом предупреждением.

Для намеренного прямого доступа из сети можно задать `0.0.0.0`, но порт 9117
следует ограничить firewall. Настройка reverse proxy и forwarded headers в этот
патч не входит.

## Ограничения контейнера API

API запускается от встроенного пользователя `app` официального .NET image.
Compose включает:

- read-only root filesystem;
- `no-new-privileges`;
- удаление Linux capabilities;
- отдельный writable tmpfs `/tmp`;
- init-процесс для корректной обработки сигналов.

PostgreSQL и его data volume этим изменением не затрагиваются.

## HTTP-защита

Публичные health endpoints возвращают только минимальный статус. Подробная
готовность доступна по защищённому маршруту `/api/v1/system/readiness`.

Kestrel ограничивает размер request body, request line и заголовков, а также
время получения заголовков. Глобальный rate limiter имеет отдельные пределы для
чтения, административных запросов и Torznab. Health endpoints не лимитируются.

Приложение выставляет CSP и базовые security headers. HSTS не включается, пока
HTTPS не является частью штатной конфигурации.
