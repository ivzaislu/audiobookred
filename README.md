## Возможности

### Аудиокниги

- 🔎 поиск аудиокниг сразу по нескольким источникам;
- 📚 каталоги, жанры, авторы, чтецы и циклы;
- 🎛️ возможность отдельно включать и отключать источники для Каталога и общего поиска;
- 🏠 настраиваемая Главная: «Новинки», «Популярное», «Продолжить слушать» и «Скачанные»;
- ▶️ встроенный аудиоплеер с главами, скоростью воспроизведения и перемоткой;
- 🏷️ короткие названия глав «Глава 1», «Глава 2» и т. д. при желании;
- 🌙 таймер сна, пропуск тишины и закладки;
- ❤️ избранное, история, библиотека и сохранение прогресса;
- ⬇️ локальное скачивание аудиокниг;
- 💾 резервное копирование и восстановление пользовательских данных и настроек;
- 🚗 MediaSession и Android Auto;
- 🌓 светлая, тёмная и системная темы;
- 🧲 поддержка RuTracker и TorrServe.

### Электронные книги

- 📖 импорт и чтение TXT, FB2, FB2.ZIP, EPUB и ZIP с книгами;
- 🔎 каталог Fantasy Worlds: поиск, страницы авторов и циклов, выбор формата книги;
- 📚 карточки книг с описанием, автором, циклом и действиями «Читать» и «Слушать»;
- 🎨 выбор шрифта, размера текста, интервалов, полей и оформления;
- 👁️ скрываемые панели для чтения и компактное управление озвучкой;
- ✨ подсветка озвучиваемого фрагмента и кнопка «К озвучке»; ручная прокрутка приостанавливает следование за голосом;
- 🔖 независимые позиции чтения и прослушивания, выделение и копирование текста;
- 🗂️ книги в Библиотеке, истории, циклах и блоке «Продолжить»;
- 📁 сохранение загруженных оригиналов в `Download/AudioBookRed/Books` и выбор переноса своего файла при импорте.

При удалении книги из библиотеки удаляются её управляемые копии. Общий архив сохраняется, пока в библиотеке остаются другие книги из него. Сохранённая озвучка остаётся доступной.

### Озвучка текста

- 🔊 озвучивание через отдельно устанавливаемый **RuVoice** с выбором голоса;
- ▶️ управление скоростью, паузой и переходами между главами;
- 🌙 таймер сна, в том числе до конца главы;
- ⬇️ сохранение главы или всей книги в **WAV** либо **M4A/AAC**;
- 🎛️ выбор битрейта AAC: 32, 48, 64, 96 или 128 кбит/с; сжатие выключено по умолчанию;
- 🎧 прослушивание готовой озвучки без установленного RuVoice.

RuVoice нужен для создания новой озвучки. Установка и выбор голоса доступны в разделе «Настройки → Чтение и озвучка». Для обычного чтения он не требуется.

| **Источник** | **Каталог** | **Поиск** | **Прослушивание** |
| --- | :---: | :---: | :---: |
| Audiopolka | ✅ | ✅ | ✅ |
| уКниг | ✅ | ✅ | ✅ |

| Книга в ухе | ✅ | ✅ | ✅ |
| Baza-Knig | ✅ | ✅ | ✅ |
| MY-AUDIOBOOKS | ✅ | ✅ | ✅ |
| Audiokniga.Life | ✅ | ✅ | ✅ |

Источники можно включать и отключать по отдельности в настройках приложения. Как минимум один источник всегда остаётся включённым.

> Доступность конкретного источника зависит от его текущей работы и структуры страниц. Для отдельных книг источник может предоставлять только ознакомительный фрагмент или метаданные.

### Электронные книги

**Fantasy Worlds** — каталог электронных книг с поиском, страницами авторов и циклов. Книги добавляются в библиотеку в одном из доступных форматов. Объединённый поиск по текстовым источникам и фильтр жанров пока не поддерживаются.

### RuTracker

RuTracker доступен как отдельный источник аудиокниг.

- для работы **поиска** необходимо указать в настройках приложения **логин и пароль RuTracker**;
- для **прослушивания и скачивания** через торрент требуется настроенный **TorrServe**;
- после полного скачивания аудиокнига может воспроизводиться локально без TorrServe.

## Совместимость

Для приложения требуется **Android 7.0 или новее** и устройство с поддержкой **ARM64 (`arm64-v8a`)**. Готовые APK и описания выпусков доступны в [Releases](https://github.com/ivzaislu/audiobookred/releases).

## Для разработчиков

<details>
<summary><strong>Стек и сборка из исходников</strong></summary>

### Стек

- Kotlin;
- Jetpack Compose;
- AndroidX Media3 / ExoPlayer / MediaSession;
- Room;
- Paging 3;
- Hilt;
- WorkManager;
- OkHttp;
- Kotlin Coroutines;
- KSP.

### Требования

- JDK 17;
- Android SDK;
- Android platform `android-37.0`;
- Build Tools `37.0.0`.

### Получение исходников

```bash
git clone https://github.com/ivzaislu/audiobookred.git
cd audiobookred
```

Укажите путь к установленному SDK в `local.properties` (`sdk.dir=...`) или через `ANDROID_HOME`. Версии зависимостей и Gradle wrapper закреплены в репозитории.

### Проверка проекта

```bash
./gradlew --no-daemon testDebugUnitTest
./gradlew --no-daemon compileDebugAndroidTestKotlin
./gradlew --no-daemon lintDebug
```

### Сборка APK

```bash
./gradlew --no-daemon assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Debug-сборка устанавливается рядом с основной версией как отдельное приложение; production-обновления для неё отключены. Для локальной debug-сборки ключ подписи официального релиза не требуется.
