# AudioBookRed

Публичный репозиторий распространения Android-приложения AudioBookRed.

Здесь публикуются готовые подписанные APK и данные для встроенного обновления приложения. Исходный код приложения хранится отдельно и в этот репозиторий не публикуется.

## Скачать приложение

Готовые версии находятся в разделе **Releases** этого репозитория.

Для каждой версии публикуются:

- `abred-android-<version>.apk` — установочный APK;
- `abred-android-<version>.apk.sha256` — SHA-256 APK;
- `abred-android-<version>.json` — metadata конкретного релиза.

Файл `latest.json` в корне репозитория используется приложением для проверки наличия новой версии.

## Обновления

Release APK собирается из закрытого исходного репозитория через GitHub Actions, подписывается production-ключом и после проверки автоматически публикуется сюда. В APK не встраиваются GitHub-токены или ключ подписи.

Перед установкой обновления приложение проверяет SHA-256, размер, `applicationId`, `versionCode` и подпись APK.
